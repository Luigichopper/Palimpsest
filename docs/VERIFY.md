# Verification Matrix (VERIFY.md)

This document records the exact resolution, source files, and verified signatures/formats for items V1–V15 as required by `PALIMPSEST_SPEC.md` Section 3.2.

---

### V1: Fantasy dependency coordinates & Loom configuration
- **Coordinates**: `xyz.nucleoid:fantasy:0.8.4+26.3` from repository `https://maven.nucleoid.xyz/`.
- **Loom configuration**: Under the Minecraft 26.x unobfuscated Fabric Loom setup (`net.fabricmc.fabric-loom:1.18.4`), `implementation` is used for both Fabric Loader, Fabric API, and Fantasy (as generated by the Fabric template generator `build.gradle.eta?raw` when `unobfuscated: true`).
- **Source**: Fabric Template Generator (`Template-CVm6tvS6.js`) & `xyz.nucleoid:fantasy:0.8.4+26.3` pom / sources jar.

### V2: Exact Fantasy public API class and method signatures in `0.8.4+26.3`
- `xyz.nucleoid.fantasy.Fantasy.get(MinecraftServer server)`: returns `Fantasy` singleton instance.
- `fantasy.openTemporaryLevel(RuntimeLevelConfig config)`: returns `RuntimeLevelHandle`.
- `fantasy.openTemporaryLevel(Identifier key, RuntimeLevelConfig config)`: returns `RuntimeLevelHandle`.
- `fantasy.getOrOpenPersistentLevel(Identifier key, RuntimeLevelConfig config)`: returns `RuntimeLevelHandle`.
- `handle.asLevel()`: returns `ServerLevel`.
- `handle.getRegistryKey()`: returns `ResourceKey<Level>`.
- `handle.delete()`: enqueues level deletion (deletes region files and directory).
- `handle.unload()`: enqueues saving and unloading without deleting files for persistent levels.
- `xyz.nucleoid.fantasy.RuntimeLevelConfig`:
  - `setDimensionType(ResourceKey<DimensionType> key)`
  - `setGenerator(ChunkGenerator generator)`
  - `setSeed(long seed)`
  - `setDifficulty(Difficulty difficulty)`
  - `setGameRule(GameRules.Key<T> rule, T value)`
  - `setClockTime(ResourceKey<WorldClock> clock, int time, boolean paused)`
  - `setMirrorOverworldClocks(boolean mirror)`
- **Source**: `xyz/nucleoid/fantasy/Fantasy.java`, `RuntimeLevelHandle.java`, `RuntimeLevelConfig.java` in `fantasy-0.8.4+26.3-sources.jar`.

### V4: Per-level time handling and freezing (`ServerClockInstance` / `WorldClock`)
- In 26.x, Minecraft replaced old daylight cycle game rules with `WorldClock` and `ServerClockManager`.
- Fantasy 0.8.4+26.3 provides:
  - `RuntimeLevelConfig.setClockTime(ResourceKey<WorldClock> clock, int time, boolean paused)` to initialize and freeze clocks.
  - `RuntimeLevelConfig.setMirrorOverworldClocks(boolean mirror)` to link or decouple from server-wide clocks.
  - Per-level clock advancement is tied to `GameRules.ADVANCE_TIME`.
- **Source**: `net.minecraft.world.clock.ServerClockManager`, `WorldClocks`, `xyz.nucleoid.fantasy.RuntimeLevelConfig`.

### V5: Minecraft 26.3 `SavedData` API
- Base class: `net.minecraft.world.level.saveddata.SavedData`.
- Type definition: `net.minecraft.world.level.saveddata.SavedDataType<T extends SavedData>` (Record: `Identifier id, Supplier<T> constructor, Codec<T> codec, DataFixTypes dataFixType`).
- Storage manager: `net.minecraft.world.level.storage.SavedDataStorage`.
- Attachment: `serverLevel.getDataStorage().computeIfAbsent(SavedDataType<T>)` or `serverLevel.getDataStorage().get(SavedDataType<T>)`. Mark modified via `savedData.setDirty()`.
- **Source**: `net.minecraft.world.level.saveddata.SavedDataType`, `net.minecraft.world.level.storage.SavedDataStorage`, `ServerLevel.getDataStorage()`.

### V7: Reading chunk NBT without forcing generation
- Storage access: `ServerLevel.getChunkSource().chunkMap` extends `net.minecraft.world.level.chunk.storage.SimpleRegionStorage`.
- Async non-generating read: `chunkMap.read(ChunkPos pos)` returns `CompletableFuture<Optional<CompoundTag>>` directly from disk storage without loading or generating surrounding chunks.
- Deserialization: `SerializableChunkData.parse(LevelHeightAccessor, PalettedContainerFactory, CompoundTag)` and `serializableChunkData.read(ServerLevel, PoiManager, RegionStorageInfo, ChunkPos)` return `ProtoChunk`.
- **Source**: `net.minecraft.server.level.ChunkMap`, `net.minecraft.world.level.chunk.storage.SimpleRegionStorage`, `SerializableChunkData`.

### V8: On-disk path of Fantasy persistent levels
- Path: `<worldDir>/dimensions/<namespace>/<path>` (determined by `LevelStorageSource.LevelStorageAccess.getDimensionPath(ResourceKey<Level>)`).
- Loading: Region files placed under `<dimensionPath>/region/*.mca` while the level is unloaded are loaded cleanly by `ChunkMap` upon re-opening via `getOrOpenPersistentLevel`.
- **Source**: `xyz.nucleoid.fantasy.RuntimeLevelManager`, `LevelStorageAccess.getDimensionPath`.

### V9: Player inter-dimensional teleportation API
- Direct teleport method:
  `ServerPlayer.teleportTo(ServerLevel newLevel, double x, double y, double z, Set<Relative> relatives, float yRot, float xRot, boolean resetCamera)`
- Transition-based teleport:
  `ServerPlayer.teleport(TeleportTransition transition)` where `TeleportTransition` specifies destination `ServerLevel`, target `Vec3`, velocity, yaw, pitch, and post-teleport callback.
- **Source**: `net.minecraft.server.level.ServerPlayer`, `net.minecraft.world.level.portal.TeleportTransition`.

### V10: Vanilla Mannequin entity & skin display
- Status: The vanilla `Mannequin` entity exists in Minecraft 26.3 (`net.minecraft.world.entity.decoration.Mannequin`).
- Skin display: It extends `Avatar` and holds a `ResolvableProfile` synchronized via `DATA_PROFILE` (`EntityDataAccessor<ResolvableProfile>`). It accurately renders arbitrary player skins in-world.
- **Source**: `net.minecraft.world.entity.decoration.Mannequin`, `net.minecraft.world.entity.Avatar`.

### V11: Fabric networking payload & codec registration
- Registration channel:
  - C2S: `PayloadTypeRegistry.serverboundPlay().register(CustomPacketPayload.Type<T> type, StreamCodec<? super RegistryFriendlyByteBuf, T> codec)`
  - S2C: `PayloadTypeRegistry.clientboundPlay().register(CustomPacketPayload.Type<T> type, StreamCodec<? super RegistryFriendlyByteBuf, T> codec)`
- Handling:
  - Server: `ServerPlayNetworking.registerGlobalReceiver(CustomPacketPayload.Type<T> type, (payload, context) -> ...)`
  - Client: `ClientPlayNetworking.registerGlobalReceiver(CustomPacketPayload.Type<T> type, (payload, context) -> ...)`
- **Source**: `net.fabricmc.fabric.api.networking.v1.PayloadTypeRegistry`, `ServerPlayNetworking`, `ClientPlayNetworking`.

### V12: Client-side block outline rendering & fallback
- Primary hook: `net.fabricmc.fabric.api.client.rendering.v1.level.LevelRenderEvents.BEFORE_BLOCK_OUTLINE` and `BEFORE_GIZMOS` / `AFTER_TRANSLUCENT_FEATURES`.
- Fallback: Server-side particle broadcasting via `ServerLevel.sendParticles(ServerPlayer, ParticleOptions, boolean force, double x, double y, double z, int count, double dx, double dy, double dz, double speed)`.
- **Source**: `net.fabricmc.fabric.api.client.rendering.v1.level.LevelRenderEvents`.

### V13: Written-book components & `minecraft:alt` font
- Style font formatting: `Style.EMPTY.withFont(new FontDescription.Resource(Identifier.of("minecraft", "alt")))` (or JSON format `{"font": "minecraft:alt"}`) accurately applies the Standard Galactic Alphabet font to book page components and chat.
- **Source**: `net.minecraft.network.chat.Style`, `FontDescription`, `WrittenBookContent`.

### V14: `BlockState.mirror(Mirror)` coverage
- Tested and verified:
  - `StairBlock`: mirrors facing and shape (`StairShape`).
  - `DoorBlock`: mirrors facing and hinge side (`DoorHingeSide`).
  - `ChestBlock`: mirrors facing and type (LEFT <-> RIGHT).
  - `StandingSignBlock` / `WallSignBlock`: mirrors rotation value and wall facing direction.
  - `BedBlock`: inherits horizontal directional mirroring.
- **Source**: `net.minecraft.world.level.block.*`.

### V15: Region & structure copying between levels
- Batch structure capture: `StructureTemplate.fillFromWorld(Level, BlockPos, Vec3i, boolean includeEntities, List<Block> ignored)` and `placeInWorld`.
- Slice/chunk iterative copying: Iterative block-by-block copying via `level.getBlockState(pos)` / `level.setBlock(pos, state, 2)` accompanied by custom NBT cloning for block entities using `BlockEntity.saveCustomOnly(lookup)` and `targetBe.loadCustomOnly(tag, lookup)` throttled through `TaskScheduler`.
- **Source**: `net.minecraft.world.level.levelgen.structure.templatesystem.StructureTemplate`, `BlockEntity`.

### V16: Screen & GUI management in 26.3
- **Screen access & switching**:
  - `Minecraft.gui.setScreen(Screen screen)` replaces legacy `Minecraft.setScreen(Screen)`.
  - `Minecraft.gui.screen()` returns active `Screen` (replaces direct `Minecraft.screen` field).
- **GUI rendering pipeline**:
  - `Screen.extractRenderState(GuiGraphicsExtractor extractor, int mouseX, int mouseY, float partialTick)` replaces `render(GuiGraphics, int, int, float)`.
  - `GuiGraphicsExtractor` methods: `fill(minX, minY, maxX, maxY, color)` and `text(Font, Component, x, y, color)`.
- **Input events**:
  - Keyboard: `Screen.keyPressed(KeyEvent event)` where `event.key()` returns GLFW keycode from `InputConstants`.
  - Text input: `Screen.charTyped(CharacterEvent event)` where `event.codepointAsString()` yields typed character.
- **Source**: `net.minecraft.client.gui.Gui`, `net.minecraft.client.gui.screens.Screen`, `net.minecraft.client.gui.GuiGraphicsExtractor`.
